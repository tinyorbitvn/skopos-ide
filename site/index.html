What works today

One window for the clusters you already run.

Everything here is in release {{release.version}}. What is not built yet is on the roadmap, further down.

Every kubeconfig, one catalog

SkoposIDE reads your kubeconfig files and lists every context in a catalog. Pin the clusters you use to the hotbar and keep several connected at once.

  • Connection state for each cluster
  • Pinned clusters on the hotbar, one click away
  • Several clusters connected at the same time

YAML beside the API docs

Edit or create any object in a YAML editor. The fields of its kind come from the cluster's own API docs, right next to the text.

  • Search and a field tree for the kind
  • Each field's type, default and description
  • The same panel in edit and create tabs
  • Field hints as you type, and AI proposals you accept or reject in the tab

Tabs, splits and windows

Open each page in a tab, split the main view to see two or three side by side, or give a tab a window of its own.

  • Up to three panes side by side
  • Move a tab to another pane or a new window
  • Tabs and windows come back on restart

A cluster at a glance

The Overview opens on what to look at first: how full the cluster is, what is failing and what uses the most.

  • CPU, memory and Pods against what the nodes can give
  • Health tiles that open the failing lists
  • The control plane's checks and the top consumers

Node topology

The cluster drawn as an architecture diagram: regions and zones as boxes, a card for each node.

  • Health, roles, conditions and taints per node
  • CPU and memory against what the node can give
  • Its Pods as squares colored by status

Logs, shell and port forward

Open a container's logs, a shell or a port forward from the details drawer. Each one opens as a tab in the dock below the list, so the list stays in view.

  • Logs of each container
  • A shell in a running container
  • Port forwards from the details drawer

Resource map

See how an object connects to the rest of the cluster: what owns it and which Pods a Service selects.

  • Each Argo CD Application drawn as a box around what it manages, down to its Pods
  • RBAC access links
  • Export the whole map or the current view as PNG or PDF

Metrics where you look

CPU and memory for Pods, workloads and Nodes, from metrics-server or a Prometheus-compatible API in the cluster.

  • Grafana Mimir and other multi-tenant APIs: scheme, path prefix and tenant
  • A cluster label for backends that hold several clusters
  • Errors and empty answers say which setting to check
What a cluster needs for metrics

Helm and Argo CD

Helm releases and Argo CD Applications have their own lists in the sidebar.

  • Each release's chart, revision and status
  • Each Application's sync state and health
  • Sync an Application from the app

Live resource tables

Each kind has its own columns, status and actions, such as scale, restart and node drain. Lists follow the cluster as it changes.

Filter by any column

Type a value to search every column, the hidden ones too, or name a column, as in status != Running or restarts > 0.

Keyboard first

A command palette and shortcuts for every view, from switching clusters to opening a shell.

AI agents that ask first

Chat with the agent CLI you already use, such as Claude Code, Codex, OpenCode or Gemini CLI. It runs as you, with a kubeconfig that holds only the chat's clusters, and asks in the chat before it runs a command or changes a cluster.

  • Each read shown as a tool card
  • Changes per cluster: Ask every time, Read only or Don't ask
  • On Linux and macOS

Tauri 2 and a Rust core

A Rust core and a React UI in a native shell. The Windows installer is {{asset:x64-setup.exe:size}}.

  • Installers for Linux, macOS and Windows
  • Signed updates from inside the app
  • Credentials stay in the core; the UI sees cluster IDs only

The pictures on this page come from the app's design canvas, which shows every screen with sample clusters.

Themes

Light or dark, like the rest of your desktop.

SkoposIDE follows your system theme, or keeps the one you pick in Preferences. The same Pods list, in the light theme.
